# Luxury Hotel Demo Agent Guide

## 1. Source of Truth
Read the relevant files in `docs/` before making product, design, UX, content, or technical changes.

## 2. Visual Rules
Use the documented colour tokens, typography direction, spacing, and quiet-luxury design language. Do not introduce bright eco-green, fake-gold gradients, heavy shadows, or flashy motion.

## 3. Content Rules
Do not invent hotel facts. Room names, amenities, ratings, offers, policies, contact details, and experiences must be verified before being presented as factual production content.

## 4. Engineering Rules
Prefer server components. Add client components only for real interaction. Keep JavaScript light, preserve accessibility, and verify lint, typecheck, and build after coherent changes.

## 5. Git Rules
Use small descriptive commits. Update documentation first when a major decision changes.
